# 作業記録を残すルール

## 適用条件

本ルールは、作業記録の保存に **Obsidian vault（`canpok1/obsidian-vault` リポジトリ）のデイリーノートを使う場合にのみ適用する**。

- `work-log` スキルは vault リポジトリの中にある。**vault 以外のリポジトリで記録するには、セッション起動時に `--add-dir` で vault の clone を参照させる**（`/add-dir` でも可）。参照させていないセッションではスキルが読み込まれないので、本ルールも適用しない。
- 記録するかどうかは、この `--add-dir` の有無でユーザーが制御する。記録が不要なセッションでは参照させない。

## 記録するタイミング

以下のタイミングでは、指示がなくても `work-log` スキルで記録を残す。

- まとまった実装・調査・デバッグが一段落したとき
- コミットやプルリクエストを作成したとき
- 方針を決めたとき（何を選び、なぜ他を選ばなかったかは後で価値を持つ）
- ユーザーが「日報」「作業記録」「ログ」に言及したとき

一問一答で終わるやり取りや、記録する価値のある内容が無いときは書かない。
