# 作業記録を残すルール

## 適用条件

本ルールは、作業記録の保存に **Obsidian vault（`canpok1/obsidian-vault` リポジトリ）のデイリーノートを使う場合にのみ適用する**。

- `work-log` スキルが展開されていない環境では適用しない。
- 実際に記録されるかどうかは vault のローカル clone を用意しているかで決まる。clone が無い環境では `work-log` スキルは何もしない（エラーにはならない）。

## 記録するタイミング

以下のタイミングでは、指示がなくても `work-log` スキルでデイリーノートに追記する。

- まとまった実装・調査・デバッグが一段落したとき
- コミットやプルリクエストを作成したとき
- 方針を決めたとき（何を選び、なぜ他を選ばなかったかは後で価値を持つ）
- ユーザーが「日報」「作業記録」「ログ」に言及したとき

一問一答で終わるやり取りや、記録する価値のある内容が無いときは書かない。
