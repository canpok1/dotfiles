# 個人設定

- メッセージ（応答・説明・コミットメッセージ等）は全て日本語で記述する。

## 再発防止策は汎用化してから入れる

失敗や不具合の対策を書くときは、**目の前の事象だけでなく、同じ原因から生じる類似の事象も防げる形にする。** 対症療法を積み上げると、列挙にないケースで同じ失敗が起きる。

- **原因を、起きた出来事ではなく仕組みの言葉で言い直す。** 「この手順でこれを忘れた」で止めず、「何がどうなると何が壊れるのか」まで戻す
- **言い直した原因が他のどこに当てはまるかを挙げる。** 1つも挙がらないなら、まだ個別の事象の言い換えにとどまっている
- **ケースの列挙ではなく軸で持たせる。** 「Aのとき」「Bのとき」と足していく形は、列挙にない C で落ちる。個別のケースは軸を理解させる例として添える
- **対策が読まれる場所に置く。** 個別の手順の中に書くと、その手順を通るときしか効かない。判断の分岐点や、その種の作業で必ず通る場所に置く
- **同じ内容を複数の場所に書かない。** 参照側は1行のポインタにする
- **何が防げて何が防げないかを述べる。** 汎用化しても残る限界は隠さない
