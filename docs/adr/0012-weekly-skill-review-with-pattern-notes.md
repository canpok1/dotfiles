# 0012. 自作スキルを週1回、つまずきのパターンを貯めてから見直す

- ステータス: 採用
- 日付: 2026-10-11

## コンテキスト

自作スキル（`claude/skills/`）は気づいた人が都度直しており、1回では気づけない繰り返しは残る。

論文 WikiSkill（arXiv 2608.27454）は実行ログから失敗パターンを知識ページに貯め、それを根拠にスキルを1件ずつ直す。効いているのはこの「貯めてから直す」部分。採否は検証の点数で決めるが、個人のスキルには検証データが無く実行回数も少ない。

## 決定

**週1回の定期実行で、つまずきをパターンとして貯め、2回以上出たものだけを根拠に修正PRを出す。採否はユーザーが決める。**

- 材料は過去1週間のセッションログと brain の作業ログ。セッションごとにサブエージェントへ読ませる
- パターンは brain の `projects/dotfiles/skill-patterns/` に1件1ノート。状態とPRリンクを frontmatter に持つ
- PRは1回最大2件。出す前に別のサブエージェントが修正案を検査する
- 月初に古いパターンを整理する
- 手順は新スキル `skill-review`。対象はまず dotfiles のスキル

## 結果

1回では気づけない繰り返しが拾われ、修正に根拠が残る。採否が人を通るので `retro` の方針と揃う。

改善の速さはPR確認に律速される。定期実行からセッションログを読めなければ、材料は作業ログに限られる。

## 検討した代替案

- **点数で自動採否（論文どおり）**: 検証データが無いため却下
- **パターンを dotfiles 内に置く**: 修正の無い週もメモ更新だけのPRが立つため却下
- **`daily-check` の1項目にする**: 毎日の処理に実行日の判定が混ざるため却下
