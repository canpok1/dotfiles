# 0012. 自作スキルを週1回、つまずきのパターンを貯めてから見直す

- ステータス: 採用
- 日付: 2026-10-11

## コンテキスト

自作スキル（`claude/skills/`）は気づいたときに直すだけで、繰り返すつまずきが残る。

論文 WikiSkill（arXiv 2608.27454）は失敗パターンを貯めてからスキルを直し、採否を検証の点数で決める。個人のスキルには検証データが無い。

## 決定

**週1回の定期実行で、つまずきをパターンとして貯め、2回以上出たものだけを根拠に修正PRを出す。採否はユーザーが決める。**

- 材料はセッションログと brain の作業ログ。サブエージェントが1件ずつ読む
- パターンは brain の `projects/dotfiles/skill-patterns/` に1件1ノート。状態とPRリンクを frontmatter に持つ
- PRは最大2件。別のサブエージェントが事前に検査する
- 月初に古いパターンを整理する
- 手順は新スキル `skill-review`。対象はまず dotfiles のスキル

## 結果

繰り返しが拾われ、修正に根拠が残る。採否が人を通り `retro` の方針と揃う。

改善の速さはPR確認次第。セッションログを読めなければ材料は作業ログだけになる。

## 検討した代替案

- **点数で自動採否（論文どおり）**: 検証データが無いため却下
- **パターンを dotfiles 内に置く**: メモ更新だけのPRが毎週立つため却下
- **`daily-check` の1項目にする**: 毎日の処理に実行日の判定が混ざるため却下
