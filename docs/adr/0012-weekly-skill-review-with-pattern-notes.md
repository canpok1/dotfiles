# 0012. 自作スキルを週1回、パターンを貯めて再現テストで自動採否する

- ステータス: 採用
- 日付: 2026-10-11

## コンテキスト

自作スキル（`claude/skills/`）は気づいたときに直すだけで、繰り返すつまずきが残る。人の確認を挟むと改善が止まりやすい。

論文 WikiSkill（arXiv 2608.27454）を忠実に再現する。失敗パターンを貯めてから1件ずつ直し、検証スコアが過去最良を超えたときだけ採用、それ以外は巻き戻す。個人のスキルには検証タスクが無いため、過去のセッションから作る。

## 決定

**週1回の定期実行で、パターンを貯め、修正案を再現テストで採点し、最良を超えたら人の確認なしで main へマージする。**

- 材料はセッションログと brain の作業ログ。サブエージェントが1件ずつ読む
- パターンは brain の `projects/dotfiles/skill-patterns/` に1件1ノート。採否に関わらず残す
- 検証タスクは過去セッションの依頼と状況。パターン抽出に使っていないものを充てる
- 採点はパターンを読ませないサブエージェントが修正前後のスキルで依頼を再現し、別のサブエージェントが判定する
- 修正案は1件ずつ。不採用なら破棄し、結果をパターンノートに記録する
- 採否の結果はユーザーへ通知する。戻すときは revert
- 手順は新スキル `skill-review`。対象はまず dotfiles のスキル

## 結果

改善が人の確認待ちで止まらない。

再現は外部への書き込みを伴わない近似で、判定も LLM なので点数は揺れる。誤った修正が全環境へ入りうる。

## 検討した代替案

- **ユーザーがPRで採否**: 改善が止まりやすいため却下
- **パターンを dotfiles 内に置く**: メモ更新だけのPRが毎週立つため却下
- **`daily-check` の1項目にする**: 毎日の処理に実行日の判定が混ざるため却下
