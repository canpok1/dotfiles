# 0012. 自作スキルを週1回、パターンを貯めて再現テストで自動採否する

- ステータス: 採用
- 日付: 2026-10-11

## コンテキスト

自作スキル（`claude/skills/`）の繰り返すつまずきが直されず残る。

論文 WikiSkill（arXiv 2608.27454）を忠実に再現する。検証スコアが最良を超えた修正だけを採用する方式。

## 決定

**週1回、修正案を再現テストで採点し、最良を超えたら人の確認なしで main へマージする。**

- 材料はセッションログと作業ログ
- パターンは brain の `projects/dotfiles/skill-patterns/` に1件1ノート
- 検証タスクはパターン抽出に使っていない過去セッションの依頼
- パターンを読ませないサブエージェントが再現し、別のサブエージェントが判定する
- 検証タスクは毎週入れ替わるため、最良は毎回現行スキルを採点し直して求める
- 修正は1回1件、週1回の実行内で最大3周
- 採否はパターンノートに記録しユーザーへ通知する。戻すときは revert
- 手順は新スキル `skill-refine`

## 結果

改善が人の確認待ちで止まらない。

再現は外部書き込みを伴わない近似で、LLM 判定なので点数は揺れる。誤った修正が全環境へ入りうる。

## 検討した代替案

- **ユーザーがPRで採否**: 改善が止まりやすいため却下
- **パターンを dotfiles 内に置く**: メモ更新だけのPRが毎週立つため却下
- **`daily-check` の1項目にする**: 毎日の処理に実行日の判定が混ざるため却下
