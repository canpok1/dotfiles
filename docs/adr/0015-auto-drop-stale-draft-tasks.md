# 0015. 作成から1ヶ月たった未判断タスクは確認せずに破棄する

- ステータス: 採用
- 日付: 2026-10-26

## コンテキスト

`daily-check` は、作成から14日以上たった着手可否が未判断のタスクを、`task-refine` 経由で確認の依頼として出している（`docs/adr/0013-user-confirmation-as-google-tasks.md`）。

2026-10-26 時点で、8/27〜9/12 に作られた5件が未判断のまま残っていた。ユーザーは個別の中身を検討せず「作られて1ヶ月を超えていたら破棄」として5件とも破棄し、これをルールにすると決めた。

## 決定

**作成から1ヶ月を過ぎた着手可否が未判断のタスクは、`daily-check` から呼ばれた `task-refine` が確認せずに破棄する。**

- 14日目の確認の依頼は残し、自動で破棄される日を添える。残したいものはそれまでに仕分けてもらう
- 破棄は理由を書いてから行い、ファイルは削除しない（`docs/adr/0006-dropped-status-for-discarded-tasks.md`）
- 経過日数は作成日で数える

`daily-check` の「判断が要るものを無人で確定させない」とは衝突しない。期限はユーザーが先に決めており、当てはめるだけで判断が残らないため。brain の食事管理で、ルール化候補を1ヶ月で確認なしに消している運用（2026-10-23 からユーザー了承済み）と同じ考え方である。

## 結果

未判断の一覧が古いもので埋まらず、確認の依頼も同じタスクについて出続けない。

破棄済みのファイルは残るので、誤って破棄したものは状態を戻せば復元できる。相談を途中で切り上げて作った未判断タスク（`discuss`）も対象になるが、判断点はファイルに残る。

防げないのは、1ヶ月以上寝かせる前提で置いたタスクも破棄されること。寝かせたいものは、理由を書いて着手可能にするか、作り直してもらう。

## 検討した代替案

- **14日目の確認をやめて、1ヶ月での自動破棄だけにする**: 通知が減るが、残したいタスクを救う機会が無くなるため却下
- **これまでどおり確認の依頼だけを出し続ける**: 判断を無人で確定させないが、5件が1ヶ月以上答えられないまま残った実績があり、依頼が溜まるだけになるため却下
