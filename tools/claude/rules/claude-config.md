# Claude 設定を変更するときのルール

Claude の設定ファイル（スキル・ルール・フック・CLAUDE.md・エージェント等）を変更する作業に適用する。

## ドキュメントへの反映

- 関連ドキュメント（README・他のスキルやルールからの参照など）への反映漏れがないか確認すること。
- スキル・ルール・エージェントの追加／削除／リネームを行った場合は、それらを名指ししている箇所（README の一覧、スクリプトから起動するスラッシュコマンド、他スキルからの参照など）を検索して漏れなく更新すること。

## 展開設定・プロファイルへの反映

展開の対応とプロファイルの許可リストは mac（`mac/home.nix`）とコンテナ（`container/setup.sh`・`container/profiles/work.conf`）に別々に持つ。**片方だけ直さないこと。**

- スキル・ルール・エージェントは `tools/claude/` 配下を丸ごと配るため、追加しても展開の対応は直さなくてよい（mac は `git add` してから `mac/setup.sh` を再実行）。それ以外の場所へ配るファイルを足したときは両方に対応を書く。
- 追加したものを仕事環境でも使うなら、`mac/home.nix` の `claudeFiles.work` と `container/profiles/work.conf` の両方へ追記する。許可リストのため、**追記しない限り仕事プロファイルでは展開されない**。
- リネーム・削除を行った場合は両方の許可リストを追従させること。

## 品質確認

- 変更後、自分が書いた内容を読み返し、記述の重複・矛盾・参照切れがないか確認すること。
- コミットする際は、論理的な変更ごとに分けること。
- **ルールや手順を足したセッションの終わりに、合計の分量を測ること。** 1行ずつは正しくても、合計が増えると読まれなくなる。増分ではなく総量で見る（2026-08-26 に meal-management スキルを1セッションで270→356行に膨らませ、あとから260行へ戻した）。
